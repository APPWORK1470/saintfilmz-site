# Saint Filmz

Portfolio and booking page for Saint Filmz: photography and film in Espoo, Finland.

- `index.html` is the whole site in one file (styles, photos and short video loops are embedded).
- Bookings are sent by WhatsApp (+358 40 461 6747) or email (saintfilmz@gmail.com) from the form on the page.
- Published with GitHub Pages from the `gh-pages` branch.
